# linmon-winlog

Public **update** repo for the LINMON Windows Event Log agent.

- Source code stays in the private `vide` repo.
- This repo only publishes **Releases** with `linmon-winlog-setup.exe`.
- On Windows: tray → **Update from GitHub…** — **no token** (public).

Latest: [Releases](https://github.com/andylee03/linmon-winlog/releases)

Tag format: `winlog-v1.0.1`
